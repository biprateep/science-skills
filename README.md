# Science Skills

This repository contains a collection of AI agent skills tailored for scientific research, brainstorming, mathematical derivation, and prototyping.

## Note on Customization

> [!WARNING]
> **Not General Purpose**
> These tools and skills are highly customized to suit the specific physics, mathematics, statistics, and AI research needs of the creator. They are not intended as general-purpose, out-of-the-box solutions for all use cases.

## Agent Compatibility

These skills have been explicitly created and optimized to work with the **Google Antigravity** agent framework. However, the core prompts, strategies, and methodologies are conceptual and should not be difficult to generalize and adapt for other AI agent frameworks.

## Featured Skills

### Co-Scientist (`skills/co-scientist`)
A comprehensive scientific research agent skill that acts as a collaborative partner. It features:
- **Rigorous Mathematical Derivations**: Enforces step-by-step math formulation without skipping lines.
- **Parallel Subagent Orchestration**: Spawns specialized Math, Literature, and Coding subagents for complex tasks.
- **Literature Grounding**: Conducts factual verification and literature reviews.
- **LaTeX Reporting**: Automatically aggregates ideas into `.tex` files and compiles them to PDFs.
