# Brainstorming Strategy Index

This directory contains individual thinking strategies and methodologies tailored for physics, mathematics, statistics, and AI research. 

When you need to brainstorm or help the user formulate hypotheses, **do not read all these files at once**. Instead, read this index to select the most appropriate strategy for the current situation, and then read the specific strategy file in the `strategies/` directory.

## Selecting a Strategy

- **SCAMPER** (`strategies/scamper.md`): Use when you want to incrementally improve, modify, or adapt existing physics models, mathematical proofs, or algorithmic architectures.
- **Six Thinking Hats** (`strategies/six_thinking_hats.md`): Use when the researcher is stuck in one mode of thinking (e.g., only seeing the mathematical flaws, or only focusing on the positive outcomes) and needs a balanced perspective.
- **Morphological Analysis** (`strategies/morphological_analysis.md`): Use for systematically exploring complex, multi-variable parameter spaces (e.g., hyperparameter search spaces, phase spaces, or simulation configurations).
- **TRIZ** (`strategies/triz.md`): Use when facing an apparent contradiction or an "impossible" requirement (e.g., needing both high precision and low computational cost).
- **Algorithmic Biomimicry** (`strategies/biomimicry_ai.md`): Use when looking for inspiration from natural systems or evolutionary mechanics to solve complex optimization or physical constraints.
- **Provocation, Random Input, and Reverse Assumptions** (`strategies/provocation_and_random.md`): Use when the conversation is stale, completely stuck, or fundamental rethinking of basic axioms is required.

## Application Note
Introduce these methods naturally into the conversation. You do not need to announce the method unless asked. Use them to guide your questions and proposals.
